# Practice index

This directory groups practice code and split notes by day. Each day folder contains the example sources used that day plus a markdown file with the lesson notes.

Available days

- day-3/ — basic I/O and inclusive sum example (inclusive_sum.cpp)
- day-5/ — for-loop and simple range examples (for_statement.cpp, decrement_count.cpp, user_range.cpp)
- day-6/ — if/else and improved range (consecutive-numbers.cpp, sum-cin.cpp, user_range_improved.cpp)
- day-8/ — Sales_item examples and the Sales_item header (Sales_item.h and associated examples)
- day-9/ — short notes on member functions (no example files added)

Each day folder contains a day-<N>.md with the lesson notes for that day.
